Other Things that need attention
------------------------
1. Look for 'MEADOW.OS REBASE' in the code. These are places NOT fixed. But,
committed out.

2. The first first comment lines in most of our files are not correct. The
first few lines often contains old copyright information, wrong file location
and the wrong date. While no technical value but, should be done. We need a
standard format to follow.

3. I added /Meadow.OS/nuttx/include/sys/boardctl.h, to Rebase, mostly
because the new rebase automation tooling indicated it was missing. However,
it doesn't seem to be needed in the build (it built without the file) and
the file only contains one entry: include <sys/boardctl.h>

4. Perhaps Meadow/nuttx/include/meadow/'meadow_syscall.h' has been
been renamed 'meadow_syscall_support.h'. Contents are different too.
Legacy Meadow at present has no references to meadow_syscall.h.
This needs to be fixed to match the most current Legacy Meadow.

5. The function hcom_nx_upd_diag_fd_inode() in
Meadow.OS/Meadow.OS/hcom_nx/hcom_nx_upd.c is not useable with Nuttx 12.
Why? Because it directly accessed internal Nuttx structures that no longer
exist in Nuttx 12. The code is currently commented out and I inserted
a syslog statement as a place holder and added MEADOW.OS REBASE so it
could be easily found,

6. Meadow.OS/meadow_os/meadow-upd.c:509 the warning: implicit declaration
of function 'stm32_pwminitialize'. Looked easy, until I started to dig. Looks
like Nuttx 12 has a totally different set of configuration options. Timers are
used for Meadow.OS and Meadow.Core. However, the timer configuration entries
are only needed by Meadow.Core.
