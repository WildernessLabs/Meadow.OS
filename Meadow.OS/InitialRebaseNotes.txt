Notes related to initial rebase effort (before 8-April-2024)

1. The top comment line in most of our files is now wrong. The top line
often contains old copyright information, wrong file location and the
wrong date, e.g. '/apps/examples/hcom/tests/hcom_dir_mgmt_tests.c'. No
technical value but, should still be done.

because the new rebase automation tooling indicated it was missing. However,
it doesn't seem to be needed in the build (it build without the file) and

Meadow.OS/Meadow.OS/meadow_os/meadow_temp_rebase.c & .h. This is

to '\comms\hcom_host_preprocess.c'. [I think this is already done]

To support the 1.2 to 1.9 effort, I added both files. Please delete
delete the old one when ready.

6. Why not remove CONFIG_MEADOW_PWR_MGMT_SUPPORT as a options as it is
always part of Meadow.OS. MEADOW_INCLUDE_CODE_FOR_ROTARY_ENCODER should also
be removed and made perminant, although it is not integrated in to

Meadow.OS/Meadow.OS/hcom_nx/hcom_nx_upd.c is no longer useable with Nuttx 12.
