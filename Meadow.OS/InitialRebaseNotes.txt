Other Things that need attention
------------------------
1. Look for 'MEADOW.OS REBASE' in the code. These are places NOT fixed. But,
are some form of workaround in the code.

2. Meadow/nuttx/include/meadow/'meadow_syscall.h' should be merged with
'meadow_syscall_support.h'.

3. The first comment lines in our files Meadow files are incorrect. The first
few lines often contains inconsistent old copyright information, a wrong file
location and the wrong date. While no technical value, it should be done. We
need a standard format to follow.

4. The defconfig file contained some entires that using 'make savedefconfig'
removed. This is the list. These may need to be added to an appropriate
Kconfig or removed as no longer needed or there name changed.
# CONFIG_MEADOW_CLOUD is not set
CONFIG_EXAMPLES_MONO=y
CONFIG_BOARD_INITTHREAD_STACKSIZE=4096
These either no longer exist in Nuttx 12 or have been renamed or have
prerequisite that were not met. Look at these one-by-one to determine
required action.

5. I (Peter) added /Meadow.OS/nuttx/include/sys/boardctl.h, to Rebase, mostly
because the new tooling (that moves files from Legacy to Rebase) indicated it
was missing. However, it doesn't seem to be needed in the build
(it builds without the file) and the file only contains one entry:
'include <sys/boardctl.h>'
